# PetForge

把**一张立绘**或**一段绿幕视频**，变成 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 桌面宠物能直接加载的**透明动画宠物包**（VP9-Alpha WebM）。

> 起因：dsh-pet 官方素材只有 Q 版角色。想换成成熟身材比例的立绘，就得自己造一套透明动画——
> 这个项目把那条链路整个自动化了。

---

## 效果

| 输入 | 输出 |
|---|---|
| 一张纯绿幕角色立绘（1280×1920 PNG） | 106 个动画名、43.5 MB 的完整宠物包 |
| 一段 10 秒绿幕动作视频（1280×720） | 一个真实动作的透明动画（240 帧） |

生成后放进 `~/.dsh/dsh-pet/pet/`，调用插件接口热加载，**无需重启应用**。

---

## 两个脚本

### `forge.py` —— 静图 → 宠物包

一张立绘生成 **6 个动作模板**，再按关键词分配到 106 个动画名：

| 模板 | 动作 | 时长 |
|---|---|---|
| `breathe` | 呼吸 + 轻微摇摆（待机、默认） | 8s |
| `bob` | 上下点头（吃东西类） | 3s |
| `hop` | 跳跃 + 压扁拉伸（开心类点击回应） | 1.5s |
| `tilt` | 左右倾斜（害羞/被吓） | 1.67s |
| `stretch` | 纵向伸展（伸懒腰） | 2.33s |
| `swing` | 悬空摆动（被拖拽） | 2.5s |

```bash
python forge.py --input 角色.png --prefix mature --name "小鲸·成人版"
python forge.py --input 角色.png --key 00FF00 --prefix mature   # 纯色背景自动抠图
```

### `videoforge.py` —— 绿幕视频 → 透明动画

把 AI 生成的动作视频转成插件能吃的透明动画，质量优先。

```bash
python videoforge.py                      # 转换 input/videos/ 下全部
python videoforge.py --only 待机呼吸休闲    # 只转一个
python videoforge.py --preview            # 只导一帧预览，不编码
```

## 工程上踩过并解决的坑

这部分是这个项目真正的价值所在，每个都是实测出来的。

### 1. VP9-Alpha 解码必须显式指定解码器

```
ffmpeg -i in.webm -pix_fmt rgba out.png                   # ❌ alpha 范围 255-255，全不透明
ffmpeg -c:v libvpx-vp9 -i in.webm -pix_fmt rgba out.png   # ✅ alpha 范围 0-255
```

原生 `vp9` 解码器**不处理透明层**，会静默丢掉 alpha，输出黑底。
透明数据在 VP9 里以 BlockAdditional 存储，只有 libvpx 解码器会合并它。

**不指定就等于白干，而且不会报错。**

### 2. 系统里的 ffmpeg 可能是残缺版

本机某 IDE 自带的 ffmpeg 是 `--disable-everything` 精简构建：
**没有 VP9 编码器，也不支持 webm 封装**，muxer 只有 `mov/mp4`。

解决：从 npm 拉 `@ffmpeg-installer/win32-x64`（包内直接带完整二进制）。

### 3. 编码太慢 → 只编模板，再复制

本机 4 核 + 2018 年版 ffmpeg，VP9-Alpha 约 **1.5–2 秒/帧**。
106 个动画逐个编码要 1 小时以上。

优化：**只真编码 6 个动作模板，再按动画名关键词复制文件**——
编码量降到 1/18，且动作仍有区分度。

### 4. 绿幕抠图的边缘残留

朴素色距抠图会留下一圈**绿色光晕**。完整流水线：

```
背景色自动探测（采样四角，兼容 AI 生成的非纯 #00FF00）
  → 色距抠图（tol + feather 半透明过渡）
  → 去绿溢（绿通道压到不超过 R/B 最大值）
  → alpha 收边 1–2px（切掉最外圈）
  → 颜色外扩（半透明像素取邻近不透明像素的颜色）
```

最终指标：**绿偏像素占比 0.000%**（含边缘带），右下水印区域 alpha 归零。

### 5. 帧间抖动与视频间不一致

以**每个视频的第一帧**做标定（官方提示词要求首帧必须是标准正面站姿），
算出缩放比例与裁剪原点，再把**同一变换套用到该视频所有帧**：

- 帧间不抖（不会每帧各自重新居中）
- 视频间一致（每段动画的角色大小、脚底位置统一）

### 6. 显示清晰度

成品 640×360，但屏幕上按 `size` 配置放大显示 + 系统 125% DPI 缩放
→ 实际是**放大**渲染，发虚。

解决：成品提到 **960×540**，让屏幕**缩小**渲染，再加反锐化蒙版补偿 AI 视频本身的软。

实测锐度（同尺寸 Laplacian 方差）：**2823 → 5932（+110%）**。

### 7. 热加载

插件运行中不会重扫宠物目录，但它的 HTTP 接口无需鉴权：

```bash
curl -X POST http://127.0.0.1:19387/dsh-pet-7340/reload
```

改完素材调一次即可生效，**不用重启宿主应用**。

## 目录结构

```
PetForge/
├─ forge.py              静图 → 宠物包（6 模板 → 106 动画）
├─ videoforge.py         绿幕视频 → 透明动画（numpy 抠像 + 标定 + 编码）
├─ prep.py               抠像流水线（抠色 / 去绿溢 / 收边 / 颜色外扩）
├─ extract_prompts.py    从官方提示词文件抽出可直接粘贴的成品
├─ prompt-角色生成.md     生成成熟比例角色立绘的 AI 提示词
└─ .gitignore
```

运行时目录（不纳入版本控制）：`input/`（素材）、`build/`（产物）、`work*/`（中间帧）。

---

## 环境要求

- Python 3.10+，`Pillow`、`numpy`
- **完整版 ffmpeg**（需 `libvpx-vp9` 编码器 + `webm` muxer）
  - 精简构建会在编码时直接失败，`forge.py` 启动时会探测路径
